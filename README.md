# gerald's machine

gmerald.xyz on clockwork, client zero. this repository holds one file the founder owns, `clockwork.json`, one
workflow that runs the machine, and `data/`, where the machine writes its ledger and its numbers every tick.
the only secret is the machine wallet's key, set as MACHINE_WALLET_KEY; the telegram bot's token is
TELEGRAM_BOT_TOKEN. clockwork never holds either.
